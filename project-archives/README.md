# Engineering project archives

This directory contains a curated, public subset of three engineering projects:

- `mmwave-visualizer`: IWR6843 target configuration and system-integration notes
- `solarcell-mppt-pcb`: STM32F401 solar-cell measurement mainboard/module files
- `stm32f411-ppg-pcb`: KiCad source and fabrication outputs for a PPG PCB

Large build binaries, installers, vendor datasheets, third-party PDFs, temporary
backups, and files containing unrelated personal names are intentionally excluded.
Each project README states what was checked and what still requires measurement.
