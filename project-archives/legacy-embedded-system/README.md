# Legacy Embedded System Architecture & Mixed-Signal Interfaces

This archive records the public scope of a 23-page hardware research portfolio
covering the Macintosh Color Classic, Olympic-S, vintage CRT interfaces,
cassette data, BlueSCSI, and a Raspberry Pi bridge concept.

## Verified scope

- Color Classic MC68030, memory, logic-board, SCSI, ADB, and serial mapping
- Olympic-S Z80-family architecture, 48 KB RAM, 16 KB ROM, RGBS, cassette, and
  64-contact expansion-bus mapping
- Five evidence levels separating direct observation, functional cross-check,
  source-document confirmation, inference, and pending measurement
- Test plans for continuity, voltage level, sync polarity, 75-ohm termination,
  ripple, cassette round-trip, and modern bridge integration

## Boundary

The public site does not claim that the Raspberry Pi bridge, DaynaPORT TCP path,
RGBS electrical characterization, or cassette SAVE/LOAD round-trip has been
completed. They remain explicit follow-up work.
