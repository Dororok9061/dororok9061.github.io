보안·데이터 보호 원칙

이 사이트는 정적 HTML, CSS, 최소 Vanilla JavaScript만 사용합니다. 로그인, 데이터베이스, 사용자 입력, 결제, 업로드, 자체 Contact backend가 없습니다.

TRANSPORT

HTTPS only

GitHub Pages HTTPS를 사용하고 배포 후 HTTP redirect, 인증서, Mixed Content를 자동 검사합니다.

BROWSER

최소 실행 코드

외부 script, analytics, 광고, chat, blockchain runtime, offline worker를 사용하지 않습니다.

DATA

공개 allowlist

승인된 설명과 sanitized 파생 asset만 배포하며 raw archive, license, token, 연구 원자료는 제외합니다.

SUPPLY CHAIN

고정된 배포 구성

Runtime package dependency 없이 빌드하며 GitHub Actions는 full commit SHA로 고정합니다.

LIMIT

플랫폼 책임 분리

GitHub Pages 가용성·엣지 방어, GitHub 계정, DNS, 로컬 PC, 외부 서비스의 책임을 분리합니다.

REPORTING

과장 없는 상태

적용하지 못한 통제는 PASS가 아니라 BLOCKED 또는 PLATFORM LIMITATION으로 기록합니다.

Data Classes

공개 파일도 기본은 비공개에서 시작합니다.

소유권·공개 승인·metadata 검사를 통과한 파생본만 PUBLIC로 분류합니다.

  1. PUBLIC — 승인된 소개, 프로젝트 요약, 공개 저장소 링크, sanitized asset
  2. INTERNAL — QA log, 미완료 초안, 운영 checklist
  3. CONFIDENTIAL — private archive, 미공개 연구, 원본 EDA 파일, 원본 사진
  4. RESTRICTED — API key, token, private key, recovery code, EDA license, 고위험 개인정보

상세 Threat Model과 검증 결과는 공개 저장소에서 관리합니다.
