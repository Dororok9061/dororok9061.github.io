Methodology

{% if page.lang == 'en' %}How every case study is rebuilt{% else %}모든 논문·프로젝트·공부 페이지를 다시 만드는 공통 절차{% endif %}

  1. {% if page.lang == 'en' %}Read the source{% else %}원본을 연다{% endif %}{% if page.lang == 'en' %}PDF, PPT, notebook, code, waveform, circuit, photograph, and report are identified before writing.{% else %}PDF·PPT·Notebook·코드·파형·회로·사진·보고서를 먼저 확인합니다.{% endif %}
  2. {% if page.lang == 'en' %}Define the question{% else %}공학 질문을 정한다{% endif %}{% if page.lang == 'en' %}Inputs, requirements, constraints, failure conditions, and expected output are written explicitly.{% else %}입력, 요구사항, 제약조건, 실패조건과 기대 출력을 분명히 적습니다.{% endif %}
  3. {% if page.lang == 'en' %}Map the system{% else %}시스템을 그린다{% endif %}{% if page.lang == 'en' %}Sensors, boards, software modules, interfaces, timing, and data flow are placed in one architecture.{% else %}센서, 보드, 소프트웨어 모듈, 인터페이스, 시간축과 데이터 흐름을 한 구조에 놓습니다.{% endif %}
  4. {% if page.lang == 'en' %}Show implementation{% else %}구현을 보여준다{% endif %}{% if page.lang == 'en' %}Code, equations, settings, screenshots, and processing stages are connected to source files.{% else %}코드, 수식, 설정, 화면과 처리 단계를 실제 파일에 연결합니다.{% endif %}
  5. {% if page.lang == 'en' %}Report results and limits{% else %}결과와 한계를 함께 적는다{% endif %}{% if page.lang == 'en' %}Metrics, plots, logs, figures, remaining tests, and next work stay on the same page.{% else %}수치, 그래프, 로그, 그림, 남은 시험과 다음 작업을 같은 페이지에 둡니다.{% endif %}
