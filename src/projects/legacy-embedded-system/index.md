Color Classic과 Olympic-S를 CPU·메모리·저장·영상·통신 계층으로 분석했다. PCB marking·OS 화면·원문 매뉴얼을 기능 블록과 인터페이스 표에 연결한다.

BlueSCSI·Raspberry Pi 연동 자료는 데이터 경로 설계와 RGBS·SCSI·카세트·TCP 계측 계획으로 구성된다.
