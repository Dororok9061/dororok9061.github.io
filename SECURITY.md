# Security Policy

## Scope

This repository publishes a static portfolio. It has no login, database,
payment, upload, comments, user HTML input, or state-changing backend.

## Reporting

Use this repository's **Security** tab and open a private vulnerability report.
Do not include credentials, license files, private research data, participant
data, or exploit payloads in a public issue.

For non-sensitive broken links or accessibility defects, use a normal issue.

## Supported version

Only the current `main` deployment is maintained. Historical Git commits and
cached copies may remain available; never treat an old or obscure URL as an
access-control boundary.

## Disclosure boundary

The project does not claim complete prevention of hacking, phishing, DDoS, or
supply-chain compromise. GitHub Pages, GitHub accounts, DNS, local devices, and
external services have separate responsibility boundaries documented in
`docs/security/SECURITY_ARCHITECTURE.md`.
