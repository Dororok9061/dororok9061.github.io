# Image and code guide

- Publish user-created or explicitly licensed assets only.
- Remove EXIF, local paths, identifiers, faces without consent, raw biosignals, tokens, license files, and private URLs.
- Use WebP with a JPEG fallback when both exist; include descriptive alt text, intrinsic width/height, and a caption that states what the image proves.
- A screenshot proves only the visible state. It does not prove a rerun, accuracy, latency, synthesis, or measurement.
- Code excerpts must be short, attributable, and free of secrets and private paths. Link to the public repository for the complete source.
- Instructor slides, papers, manuals, competition data, and test files are summarized rather than copied.
