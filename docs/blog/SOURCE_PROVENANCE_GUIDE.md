# Source provenance guide

Record the source owner, artifact type, public URL when available, pages or section, and how it was used. Use these independent labels:

- `Existing Archive`: historical output with context.
- `Rerun`: fresh command/procedure and output.
- `Portfolio Redraw`: explanatory reconstruction from cited values.
- `Proposal`: pre-implementation design.

Then record claim status separately as SOURCE, EXECUTED, MEASURED, PAPER_REPORTED, BLOCKED, or PLATFORM LIMITATION. Never infer one axis from the other.
