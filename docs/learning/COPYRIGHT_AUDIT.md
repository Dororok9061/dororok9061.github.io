# Copyright audit

| Material | Classification | Decision |
|---|---|---|
| User-authored public project source and sanitized figures | USER_CREATED_PUBLIC | link or reuse with provenance |
| Original course notebooks and generated submissions | USER_MODIFIED_PRIVATE / KAGGLE_RESTRICTED | do not publish |
| Clean-room rerun scripts, compact result reports, sanitized review notebooks | USER_CREATED_DERIVATIVE | publish with course provenance, validation protocol, and blocked leaderboard state |
| Course slides, PDFs, supplied notebooks, Classroom attachments | INSTRUCTOR_MATERIAL | do not copy; paraphrase only |
| Papers, manuals, datasheets, PADS vendor files | THIRD_PARTY_COPYRIGHTED | cite official source; no page or screenshot copying |
| Kaggle train/test data and invite-only rules | KAGGLE_RESTRICTED | never redistribute |
| Public library documentation | OPEN_LICENSED when license is verified | quote minimally and link |

The site contains no copied course PDF, instructor notebook, Kaggle dataset, competition test file, vendor installer, or third-party paper page.
